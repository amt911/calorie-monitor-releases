# Calorie Monitor — Releases

This repository hosts the signed APK builds of **Calorie Monitor** for Android. It contains no source code.

Releases are published automatically by CI:

- **Stable** — tags `vX.Y.Z`, built from version tags.
- **Beta** — tags `beta-<sha>`, marked as pre-releases.

The app's in-app updater reads the releases in this repository to offer new versions, so do not delete or rename them by hand.

## Install

Download the `.apk` from the latest release and open it on your Android device. You may need to allow installs from unknown sources.
